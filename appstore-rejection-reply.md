# App Store Rejection Reply — Guideline 1.1.6

## Reply to App Review Team

Hello App Review Team,

Thank you for your feedback regarding Guideline 1.1.6. We have made significant changes to clearly distinguish our app as a **fictional story creation tool** and remove any elements that could be mistaken for real messaging platforms. Here is a summary of all changes:

### 1. All iMessage Branding Removed
- Removed **FaceTime video icon** from all chat headers (in-app editor, video export renderer, and screenshot export)
- Changed theme name from "iMessage" to **"Classic"**
- Changed input placeholder text from "iMessage" to **"Enter text"**
- Removed all iMessage-specific terminology throughout the app

### 2. Visual Differentiation
- Changed sender bubble color from iOS blue (`#007AFF`) to a distinct **coral color** (`#E07B5E`) — clearly different from any real messaging app
- Added a **"Story Mode" banner** at the top of the editor screen with a book icon and "Editing" label, making it clear the user is creating fiction
- Characters display **initial letters** as avatars (not the iOS person icon)

### 3. Screenshot Export Removed
- Completely removed the **screenshot/PNG export** feature — the app now only exports **video** format
- This prevents users from creating static images that could be mistaken for real conversations
- Video exports include typing animations, making it clear the content is generated/fictional

### 4. Disclaimers Added
- Added a **first-launch disclaimer modal** that users must acknowledge before using the app, clearly stating:
  - All conversations are fictional
  - Do not use to impersonate real people
  - Do not use to spread misinformation
  - Content is for entertainment only
- Added an **export warning confirmation** before every video export reminding users the content is fictional

### 5. Language Changes
- Sample conversation text changed from "fake chat" to **"fictional story conversations"**
- App subtitle: **"Textery - Story Video Creator"** — emphasizes story/fiction, not messaging
- All in-app copy reinforces that this is a **story creation** tool

### 6. Context Menu Simplified
- Removed delivery status options (Delivered/Read) from the message context menu
- Simplified to only essential editing actions (Edit and Delete)

We believe these changes thoroughly address Guideline 1.1.6 by:
- Removing all association with real messaging platforms
- Adding multiple layers of disclaimers about fictional content
- Visually differentiating the app from any real messaging interface
- Limiting export to video-only format (no static screenshots that could be mistaken as real)

We appreciate your review and are happy to make any additional changes if needed.

Best regards,
Kim
